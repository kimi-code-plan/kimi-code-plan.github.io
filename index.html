What a kimi code plan actually includes

Kimi Code is Moonshot AI's coding agent, and the product page is unusually direct about the shape of the offer: one subscription, code anywhere. The same plan covers a desktop app, a command line tool and IDE plugins, which is the detail worth checking against competitors who charge per surface or meter the terminal separately. The agent itself is described as running on your computer, with four documented jobs: writing and editing code to implement features, fix bugs and refactor; reading and analysing an existing codebase; running commands such as tests and builds and then verifying the results; and looking things up by searching the web or reading a page. That last one matters more than it sounds, because an agent that cannot read current documentation guesses at API changes.

The K3 condition

A banner across the product page announces that K3 is available and supports up to one million context tokens. Directly under the plan section sits a single line of fine print: K3 is available on certain plans and above. Those two sentences are the whole tier story. The headline capability is not on every subscription, and the page does not spell out which one is the threshold, so the model you get depends on where you land in the list. Treat a million-token context as the reason to move up a tier rather than as something the entry plan includes. The same section notes that buying any of the listed plans also brings the other Kimi membership benefits, so the coding agent is bundled into a broader subscription rather than sold alone.

Why the prices are not on this page

Moonshot publishes membership pricing at a dedicated page, and that page returned nothing when it was fetched for this review, so no figure appears here. That is a fetch failure rather than evidence of hidden pricing, and it is the one gap worth closing yourself before you buy. Open the membership pricing page directly, note which tier carries K3, and check whether the coding agent is included at your intended level or sits one step up. Be sceptical of third-party pages quoting exact monthly rates, including converted currency figures, unless they show the tier name alongside the number. Plan structures at this company have changed as models shipped, and a rate copied from a six-month-old article is not evidence of anything.

Where the real documentation lives

Three places, all reachable from the product page. The English documentation sits under the Kimi Code docs path and is the only source that will tell you current command syntax and configuration. A console gives you account and usage views. And Moonshot maintains public GitHub repositories for both the CLI and Kimi Code, which is where install instructions, issues and release notes accumulate. If you are evaluating rather than committing, read the issue tracker before the marketing page: an agent that runs commands on your machine is judged by how it handles failure, and that story is told in bug reports, not in a feature list. Release notes are also the fastest way to see how quickly the tool is moving, which decides how soon any tutorial you find goes stale.
